O prompt diz quem você é e onde está: em ifsc@mint:~$, o ~ é a sua pasta pessoal. Antes de rodar um comando com sudo, confira o que ele faz.

Antes do Passo 1: instale o neofetch

O neofetch mostra o logo e os dados do sistema. Instale e coloque no .bashrc, o arquivo que o bash lê toda vez que o terminal abre. Assim ele aparece sempre que você abrir um terminal novo.

terminal
sudo apt update  # atualiza a lista de pacotes
sudo apt install -y neofetch  # instala o neofetch
echo "neofetch" >> ~/.bashrc  # faz o neofetch rodar ao abrir o terminal
source ~/.bashrc  # lê o .bashrc de novo, sem fechar o terminal

O >> acrescenta a linha no fim do arquivo, sem apagar o que já existe. Você vai estudar isso no Passo 2. O source faz o bash ler o arquivo de novo, por isso o neofetch já aparece agora.

Depois: zere o histórico

Os comandos que você digitar serão a sua entrega no SIGAA. Limpe a tela e o histórico agora, para o arquivo final ter só os comandos desta aula.

terminal
clear  # limpa a tela do terminal
history -c  # apaga o histórico da sessão atual
history -w  # grava o histórico (agora vazio) no arquivo

O símbolo |

O pipe manda a saída de um comando para o próximo: ps aux | grep firefox. Você vai usá-lo na aula toda.

Revisão em 1 minuto

terminal
cd ~ && pwd  # && só roda o segundo se o primeiro deu certo
ls -lah  # detalhes, ocultos e tamanhos
mkdir -p treino && touch treino/x.txt && ls treino  # cria a pasta, cria o arquivo e lista o conteúdo
rm -r treino  # apaga a pasta treino e tudo dentro dela
free -h && df -h /  # mostra a memória e depois o espaço em disco

Cuidados

rm não tem lixeira

O que o rm apaga some de vez. Confira o caminho com ls antes.

sudo só quando precisar

Com sudo o comando roda como administrador. Um erro pode quebrar o sistema, então leia o comando antes de apertar Enter.

Passo 02 · VM

Escreva e leia arquivos de texto

Veja a diferença entre > e >>, edite no nano, leia só uma parte do arquivo e filtre texto com grep.

  1. 1

    Grave com echo: > apaga, >> acrescenta

    Um > cria o arquivo ou substitui tudo que havia nele. Dois >> acrescentam no final. (FREE SOFTWARE FOUNDATION, [s.d.]a)

    terminal
    cd ~/aula2/docs  # entra na pasta docs
echo "Ana" > alunos.txt  # cria o arquivo com a linha Ana (substitui o que havia)
echo "Bruno" >> alunos.txt  # acrescenta Bruno no fim do arquivo
echo "Carla" >> alunos.txt  # acrescenta Carla no fim do arquivo
cat alunos.txt  # mostra o conteúdo do arquivo
cat -n alunos.txt  # -n numera as linhas
    saída esperada
         1	Ana
     2	Bruno
     3	Carla
  2. 2

    Edite no nano

    Abra o arquivo, acrescente Diego e Eva em linhas novas, salve com Ctrl+O e Enter, e saia com Ctrl+X.

    terminal
    nano alunos.txt  # abre o arquivo no editor nano
    TeclaO que faz
    Ctrl+OSalvar (confirme com Enter)
    Ctrl+XSair
    Ctrl+WProcurar uma palavra
    Ctrl+K / Ctrl+URecortar / colar a linha
  3. 3

    Leia só uma parte do arquivo

    Para arquivos grandes, não use cat. Veja só o começo ou só o fim.

    terminal
    head -n 2 alunos.txt  # 2 primeiras linhas
tail -n 2 alunos.txt  # 2 últimas linhas
  4. 4

    Filtre com grep

    O grep mostra só as linhas que têm a palavra procurada.

    terminal
    grep "Bruno" alunos.txt  # mostra só as linhas que têm Bruno
grep -i "carla" alunos.txt  # -i ignora maiúsculas
grep ifsc /etc/passwd  # sua linha no cadastro de usuários
    saída esperada
    Bruno
Carla
ifsc:x:1000:1000:ifsc,,,:/home/ifsc:/bin/bash
Passo 03 · VM · sudo

Crie usuários e grupos

Cada pessoa que usa o computador tem um usuário. Os grupos juntam usuários que precisam das mesmas permissões. Estes comandos mudam o sistema, por isso começam com sudo, que pede a sua senha. (CANONICAL, [s.d.]b)

  1. 1

    Crie a usuária maria sudo

    O adduser pede a senha da maria duas vezes e depois pergunta nome completo, sala e telefone. Aperte Enter nesses campos e responda S no final. (UBUNTU MANPAGES, [s.d.]a)

    terminal
    sudo adduser maria  # cria o usuário maria (pede a senha dela)
id maria  # mostra UID, GID e grupos
ls /home  # a pasta /home/maria foi criada

    O sudo pede a senha do ifsc, não a da maria. Ao digitar a senha, nada aparece na tela. É normal.

  2. 2

    Crie um grupo e coloque os dois usuários nele sudo

    Crie o grupo projeto e adicione maria e ifsc. O -aG acrescenta o grupo sem tirar os outros.

    terminal
    sudo groupadd projeto  # cria o grupo projeto
sudo usermod -aG projeto maria  # acrescenta a maria ao grupo projeto
sudo usermod -aG projeto ifsc  # acrescenta o ifsc ao grupo projeto
getent group projeto  # lista os membros do grupo
    saída esperada (o número pode mudar)
    projeto:x:1002:maria,ifsc

    Esqueceu o a e digitou só -G? O usuário sai de todos os outros grupos. Sempre use -aG.

  3. 3

    Troque de usuário e volte

    Entre como maria, usando a senha que você criou para ela. Repare que o prompt muda de nome e de pasta.

    terminal
    su - maria  # digite a senha da maria
whoami  # mostra o usuário atual
pwd  # /home/maria
exit  # volta para o ifsc
  4. 4

    Comandos de manutenção

    Conheça os outros comandos de contas. Só rode o deluser no fim do desafio, se quiser limpar.

    ComandoO que faz
    sudo passwd mariaTroca a senha de outro usuário. Sem nome, troca a sua.
    groups ifscLista os grupos de um usuário.
    sudo gpasswd -d maria projetoTira a maria do grupo projeto.
    sudo usermod -aG sudo mariaDá à maria o direito de usar sudo.
    sudo deluser --remove-home mariaApaga a usuária e a pasta dela.
    cat /etc/passwd · cat /etc/groupArquivos onde ficam usuários e grupos.
Passo 04 · VM

Controle quem lê, escreve e executa

Todo arquivo tem um dono, um grupo e três permissões para cada um. Você vai ler as permissões e mudá-las com chmod, em letras e em números. Este passo usa os arquivos alunos.txt (Passo 2) e relatorio.txt (Passo 1). (CANONICAL, [s.d.]a) (FREE SOFTWARE FOUNDATION, [s.d.]b)

  1. 1

    Leia a coluna de permissões

    Rode ls -l e olhe os 10 primeiros caracteres. Eles se dividem em 1 tipo + 3 grupos de 3 letras: dono, grupo e outros.

    terminal
    ls -l ~/aula2/docs/alunos.txt  # mostra as permissões do arquivo
    saída esperada (no Mint o arquivo novo nasce assim)
    -rw-rw-r-- 1 ifsc ifsc 26 nov 16 10:12 alunos.txt
    como ler
    tipo  dono  grupo  outros
 -    rw-   rw-    r--
 |     |     |      |
 |     |     |      +-- qualquer outra pessoa: só lê
 |     |     +--------- usuários do grupo ifsc: leem e escrevem
 |     +--------------- o dono (ifsc): lê e escreve
 +--------------------- tipo: - arquivo, d pasta, l atalho
    LetraSignifica
    rread: ler o arquivo, ou listar o conteúdo da pasta
    wwrite: alterar o arquivo, ou criar e apagar dentro da pasta
    xexecute: rodar o arquivo como programa, ou entrar na pasta com cd
    -Esta permissão não existe
  2. 2

    Entenda as permissões em número (octal)

    O chmod também aceita um número de 3 dígitos, um para o dono, um para o grupo e um para os outros. Cada letra vale um número e você soma as que estiverem ligadas:

    LetraValor
    r (ler)4
    w (escrever)2
    x (executar)1
    - (nada)0

    Como cada dígito soma de 0 a 7 (4+2+1), existem só 8 combinações. Esta é a tabela completa:

    DígitoLetrasContaPode…
    0---0nada
    1--x1só executar
    2-w-2só escrever
    3-wx2+1escrever e executar
    4r--4só ler
    5r-x4+1ler e executar
    6rw-4+2ler e escrever
    7rwx4+2+1tudo

    Para montar o número, faça a conta de cada grupo. Para ler um número, faça o caminho de volta:

    exemplos
    MONTAR  rw-  r--  ---

  dono    rw-  4+2  = 6
  grupo   r--  4    = 4
  outros  ---  0    = 0

  resultado: chmod 640 arquivo

LER  chmod 755 arquivo

  7 = rwx  dono: faz tudo
  5 = r-x  grupo: lê e executa
  5 = r-x  outros: lê e executa
    DígitoPara decorar
    7tudo: ler, escrever e executar
    6ler e escrever (sem executar)
    5ler e executar (sem alterar)
    4só ler
    0nenhum acesso

    Em pastas, o x é o que permite entrar com cd. Por isso pastas costumam ser 755 ou 770, e arquivos comuns 644 ou 664. Um 666 em arquivo funciona, mas nunca use 777: libera tudo para todo mundo.

  3. 3

    Mude com letras ou com números

    Com letras, chmod diz quem (u dono, g grupo, o outros, a todos), o quê (+ liga, - desliga, = define) e qual permissão. Com números, você define as três de uma vez. Rode o ls -l depois de cada mudança para ver o resultado.

    terminal
    cd ~/aula2/docs  # entra na pasta docs
ls -l alunos.txt  # permissões de partida
chmod o-r alunos.txt  # tira a leitura dos outros
ls -l alunos.txt  # confere as permissões depois da mudança
chmod g-w alunos.txt  # tira a escrita do grupo
ls -l alunos.txt  # confere as permissões depois da mudança
chmod 664 alunos.txt  # volta ao original, em números
chmod 600 relatorio.txt  # só o dono lê e escreve
ls -l relatorio.txt  # confere as permissões do relatório
    saídas esperadas, na ordem dos ls -l
    -rw-rw-r-- 1 ifsc ifsc 26 nov 16 10:12 alunos.txt
-rw-rw---- 1 ifsc ifsc 26 nov 16 10:12 alunos.txt
-rw-r----- 1 ifsc ifsc 26 nov 16 10:12 alunos.txt
-rw------- 1 ifsc ifsc  0 nov 16 10:15 relatorio.txt
    NúmeroPermissão
    755rwxr-xr-x · scripts e pastas
    644rw-r--r-- · arquivos comuns
    664rw-rw-r-- · arquivos que o grupo também edita
    700rwx------ · pasta privada
    600rw------- · arquivo privado
Passo 05 · VM

Escreva e rode o seu primeiro script

Um script é um arquivo de texto com comandos em sequência. Com permissão de execução, ele vira um comando novo. A pasta ~/aula2/scripts vem do Passo 1.

  1. 1

    Escreva o script

    Abra o arquivo no nano e digite o conteúdo abaixo. A primeira linha (#!/bin/bash) diz qual programa executa o script.

    terminal
    nano ~/aula2/scripts/info.sh  # abre o script no nano
    info.sh
    #!/bin/bash  # o bash executa este script
# info.sh - mostra um resumo da máquina
NOME=$(whoami)  # guarda o nome do usuário na variável NOME
echo "Olá, $NOME!"  # mostra a saudação
echo "Hoje é $(date +%d/%m/%Y) e são $(date +%H:%M)."  # mostra a data e a hora
echo "Máquina: $(hostname)"  # mostra o nome da máquina
echo "Ligada há: $(uptime -p)"  # mostra há quanto tempo está ligada
  2. 2

    Dê permissão e execute

    Sem o x, o sistema recusa. O ./ diz que o script está na pasta atual.

    terminal
    cd ~/aula2/scripts  # entra na pasta dos scripts
./info.sh  # Permissão negada
chmod +x info.sh  # dá permissão de execução ao script
./info.sh  # executa o script da pasta atual
bash info.sh  # outra forma: chama o bash direto, não precisa do x
    saída esperada
    Olá, ifsc!

Passo 06 · VM

Compacte e extraia arquivos

Compactar junta vários arquivos em um só e reduz o tamanho. No Linux o formato mais comum é o .tar.gz; para trocar com Windows, use .zip. Você vai compactar a pasta ~/aula2 do Passo 1. (FREE SOFTWARE FOUNDATION, [s.d.]c)

  1. 1

    Crie um .tar.gz

    Volte para ~ e compacte a pasta da aula inteira.

    terminal
    cd ~  # vai para a sua pasta pessoal
tar -czvf aula2.tar.gz aula2/  # cria o .tar.gz com a pasta aula2
ls -lh aula2.tar.gz  # mostra o tamanho do arquivo compactado
du -sh aula2  # tamanho da pasta original
    OpçãoO que faz
    -cCria um arquivo novo
    -xExtrai
    -tLista o conteúdo sem extrair
    -zCompacta com gzip (.gz)
    -vMostra cada arquivo (verbose)
    -f nomeNome do arquivo .tar.gz (sempre por último)
    -C pastaExtrai dentro de outra pasta
  2. 2

    Veja o que tem dentro e extraia em outro lugar

    Liste sem extrair e depois extraia numa pasta nova.

    terminal
    tar -tzvf aula2.tar.gz  # lista
mkdir ~/restaura  # cria a pasta onde vai extrair
tar -xzvf aula2.tar.gz -C ~/restaura  # extrai dentro de ~/restaura
ls ~/restaura/aula2  # confere o que foi extraído
    saída esperada
    docs  docs_copia  scripts
  3. 3

    Use zip e unzip sudo

    Instale os dois programas (se já estiverem instalados, o apt avisa).

    terminal
    sudo apt update  # atualiza a lista de pacotes
sudo apt install -y zip unzip  # instala os programas zip e unzip
zip -r aula2.zip aula2/  # compacta a pasta em .zip
unzip -l aula2.zip  # lista
unzip aula2.zip -d ~/restaura_zip  # extrai o .zip em outra pasta
  4. 4

    Compacte um arquivo só com gzip

    O gzip troca o arquivo original pela versão .gz. O gunzip desfaz.

    terminal
    cp /etc/services ~/servicos.txt  # copia um arquivo para testar o gzip
ls -lh ~/servicos.txt  # mostra o tamanho antes de compactar
gzip ~/servicos.txt  # compacta (troca por servicos.txt.gz)
ls -lh ~/servicos.txt.gz  # mostra o tamanho depois de compactar
gunzip ~/servicos.txt.gz  # descompacta e volta ao original
Passo 07 · VM

Controle processos e encerre com kill

Cada programa em execução é um processo com um número, o PID. Você vai abrir o Firefox, descobrir o PID dele no terminal e encerrá-lo com o kill. (KERRISK, [s.d.])

  1. 1

    Abra o Firefox

    Abra pelo menu do Linux Mint, entre em qualquer site e deixe a janela aberta. Depois volte ao terminal.

    MenuInternetFirefox
  2. 2

    Liste o processo no terminal

    O Firefox abre vários processos, todos com o nome firefox. O pgrep -a lista todos e o pgrep -o mostra só o mais antigo, que é o principal. O número no começo é o PID: anote o seu, ele muda a cada vez.

    terminal
    pgrep -a firefox  # lista os processos do Firefox, com o PID
pgrep -o firefox  # só o PID do processo principal
ps aux | grep firefox  # outra forma, a última linha é o próprio grep
    saída esperada do pgrep -a (os PIDs mudam)
    3127 /usr/lib/firefox/firefox
3290 /usr/lib/firefox/firefox -contentproc -childID 1 ...
3341 /usr/lib/firefox/firefox -contentproc -childID 2 ...
  3. 3

    Encerre o Firefox com kill

    Use o PID do processo principal. A janela do Firefox deve fechar. Se ela travar e não fechar, force com kill -9.

    terminal
    kill 3127  # troque 3127 pelo seu PID
kill -9 3127  # só se o kill comum não funcionar
    ComandoO que faz
    kill PIDPede para o programa encerrar (sinal 15). Tente sempre este primeiro.
    kill -9 PIDMata na hora (sinal 9). Pode perder o que não foi salvo.
    pkill firefoxEncerra todos os processos com esse nome, sem precisar do PID.
Passo 08 · VM · sudo

Instale com apt e Flatpak, e brinque com o cowsay

O apt instala programas dos repositórios do Linux Mint. O Flatpak instala programas do Flathub, que vêm com tudo que precisam. (LINUX MINT, [s.d.]) (FLATPAK, [s.d.])

  1. 1

    Instale programas divertidos sudo

    O fortunes-br traz frases em português. O sudo pede a sua senha.

    terminal
    sudo apt update  # atualiza a lista de pacotes
sudo apt install -y cowsay fortune-mod fortunes-br sl  # instala os programas divertidos
  2. 2

    Confira o Flatpak

    O Linux Mint já vem com o Flatpak e o repositório Flathub configurados.

    terminal
    flatpak --version  # mostra a versão do Flatpak
flatpak remotes  # lista os repositórios configurados
    saída esperada
    Name     Options
flathub  system

    Não apareceu o flathub? Instale e configure: sudo apt install -y flatpak e depois flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo.

  3. 3

    Instale um programa por Flatpak

    Vamos instalar o Visual Studio Code, um editor de código. A primeira instalação baixa também o runtime (algumas centenas de MB) e pode pedir a sua senha.

    terminal
    flatpak search "visual studio code"  # procura no Flathub
flatpak install -y flathub com.visualstudio.code  # instala o VS Code pelo Flathub
flatpak list --app  # lista os apps instalados por Flatpak
flatpak run com.visualstudio.code  # abre o VS Code; feche a janela para voltar

Passo 09 · VM

Agende tarefas com o crontab

O cron roda comandos sozinho em horários marcados: backup toda noite, limpeza toda semana. Cada usuário tem a sua lista, o crontab. Aqui a tarefa vai ser fazer a vaquinha aparecer no seu terminal a cada minuto. Ela precisa do cowsay instalado no Passo 8. (UBUNTU MANPAGES, [s.d.]b)

  1. 1

    Confira se o cron está rodando

    terminal
    systemctl is-active cron  # diz se o serviço cron está ativo
# se aparecer inactive ou "not found": sudo apt install -y cron
    saída esperada
    active
  2. 2

    Entenda os 5 campos de horário

    Cada linha do crontab tem 5 campos de tempo e depois o comando. O * significa "todos".

    formato
    # ┌──── minuto (0-59)
# │ ┌──── hora (0-23)
# │ │ ┌──── dia do mês (1-31)
# │ │ │ ┌──── mês (1-12)
# │ │ │ │ ┌──── dia da semana (0-6, 0 = domingo)
# │ │ │ │ │
  * * * * *  comando
    LinhaQuando roda

  3. 3

    Descubra o nome do seu terminal

    O cron roda fora do terminal. Para a vaquinha aparecer na sua tela, a saída dela será enviada para o terminal em que você está. O comando tty mostra o nome dele.

    terminal
    tty  # mostra o nome do seu terminal
    saída esperada (o número pode mudar)
    /dev/pts/0

    Anote o número do seu terminal. Se você abrir outro terminal, ele terá outro número.

  4. 4

    Crie a tarefa da vaquinha

    Abra o crontab. Na primeira vez ele pergunta o editor: digite 1 para o nano. Vá até o fim do arquivo e acrescente a linha abaixo, trocando o 0 de /dev/pts/0 pelo seu número. Salve com Ctrl+O, Enter e saia com Ctrl+X.

    terminal
    crontab -e  # abre a sua lista de tarefas para editar
    linha para colar no fim do crontab
    * * * * * /usr/games/cowsay "Aprendi crontab no IFSC!" > /dev/pts/0  # todo minuto: a vaca aparece no terminal

    No crontab use sempre o caminho completo do comando (/usr/games/cowsay). O cron não sabe em que pasta você está.

  5. 5

    Espere a vaquinha aparecer

    Em até 1 minuto a vaquinha aparece no seu terminal e se repete a cada minuto. Se o prompt sumir, aperte Enter. Veja também a lista de tarefas:

    terminal
    crontab -l  # lista as suas tarefas agendadas
    a cada minuto, no seu terminal

  6. 6

    Desligue a tarefa

    Abra o crontab -e e ponha # no começo da linha (desativa) ou apague a linha. O crontab -r apaga todas as suas tarefas de uma vez, cuidado.

    terminal
    crontab -e  # comente a linha com #
crontab -l  # lista as suas tarefas agendadas

Erros comuns

A vaquinha não aparece

O número do terminal está errado (rode tty de novo) ou o terminal foi fechado. Confira também se a linha usa /usr/games/cowsay.

crontab: no crontab for ifsc

Ainda não existe nenhuma tarefa. Crie a primeira com crontab -e.

Desafio · VM

Backup automático a cada 30 segundos

Junte tudo da aula: um script que compacta a pasta ~/aula2 com data e hora no nome e guarda o arquivo em /home/ifsc/Downloads. O cron roda o script sozinho a cada 30 segundos. Você vai usar a pasta do Passo 1, o chmod +x do Passo 5, o tar do Passo 6 e o crontab do Passo 9.

Cron só chega a 1 minuto

A menor repetição do cron é de 1 minuto. Para rodar a cada 30 segundos, use duas linhas: uma roda no começo do minuto e a outra espera 30 s com sleep 30.

Nome único e rotação

$(date +%Y-%m-%d_%H%M%S) põe os segundos no nome e evita arquivos repetidos. O tail -n +11 pega do 11º em diante, para apagar os mais antigos e guardar só 10.

  1. 1

    Escreva o script backup.sh VM

    terminal
    nano ~/aula2/scripts/backup.sh  # abre o script de backup no nano
    backup.sh
    #!/bin/bash  # o bash executa este script
# backup.sh - compacta ~/aula2 e guarda em Downloads (mantém os 10 mais novos)
DESTINO=/home/ifsc/Downloads  # pasta onde os backups ficam
mkdir -p "$DESTINO"  # cria a pasta se ainda não existir
ARQ="$DESTINO/aula2_$(date +%Y-%m-%d_%H%M%S).tar.gz"  # nome do arquivo com data e hora
tar -czf "$ARQ" -C /home/ifsc aula2  # compacta a pasta aula2
echo "$(date '+%d/%m %H:%M:%S') backup criado: $ARQ" >> "$DESTINO/backup.log"  # anota o backup no arquivo de registro
ls -t "$DESTINO"/aula2_*.tar.gz | tail -n +11 | xargs -r rm --  # apaga os backups mais antigos (guarda 10)
  2. 2

    Torne executável e teste à mão VM

    terminal
    chmod 700 ~/aula2/scripts/backup.sh  # só o dono lê, escreve e executa
~/aula2/scripts/backup.sh  # roda o backup uma vez, à mão
ls -lh ~/Downloads  # confere o backup criado
cat ~/Downloads/backup.log  # mostra o registro dos backups
  3. 3

    Agende a cada 30 segundos VM

    Abra o crontab e acrescente as duas linhas no fim. Deixe a vaquinha do Passo 9 comentada com #, para ela não atrapalhar.

    terminal
    crontab -e  # abre a sua lista de tarefas para editar
    duas linhas para o crontab
    * * * * * /home/ifsc/aula2/scripts/backup.sh  # todo minuto, no segundo 0
* * * * * sleep 30 && /home/ifsc/aula2/scripts/backup.sh  # todo minuto, espera 30 s e roda
  4. 4

    Prove que funcionou VM

    • crontab -l mostra as duas linhas do backup.
    • Depois de 2 minutos, ls -lt ~/Downloads mostra arquivos .tar.gz com horários 30 segundos afastados.
    • tail -f ~/Downloads/backup.log ganha uma linha nova a cada 30 s (Ctrl+C sai).
    • Depois de 5 minutos, a pasta continua com só 10 arquivos aula2_*.tar.gz.
    • tar -tzf em um deles lista os arquivos da aula.

Em caso de erros, para desfazer o desafio: apague ou comente as duas linhas com crontab -e e rode rm ~/Downloads/aula2_*.tar.gz ~/Downloads/backup.log. Para limpar a aula toda: sudo deluser --remove-home maria, sudo groupdel projeto e rm -r ~/aula2 ~/restaura ~/restaura_zip ~/aula2.tar.gz ~/aula2.zip.

Entrega · SIGAA

Entregue o histórico de comandos

O terminal guarda tudo o que você digitou. Esse histórico é a prova de que você fez o passo a passo e o desafio. Faça a entrega só depois de terminar o desafio.

  1. 1

    Exporte o histórico para exercicios.txt

    O history lista tudo o que você digitou. O > grava a lista num arquivo na sua pasta pessoal.

    terminal
    history > ~/exercicios.txt  # grava o histórico no arquivo exercicios.txt
cat ~/exercicios.txt  # mostra o arquivo para conferir
ls -l ~/exercicios.txt  # confirma que o arquivo existe
  2. 2

    Poste no SIGAA

    Entre no SIGAA, abra a Turma Virtual da disciplina, vá na tarefa desta aula e anexe o exercicios.txt. No seletor de arquivos ele está na Pasta Pessoal.

    SIGAATurma VirtualTarefasEnviar exercicios.txt

Fechou o terminal sem querer? O Linux guarda o histórico ao fechar a janela. Abra outro e rode history > ~/exercicios.txt mesmo assim. Se o arquivo vier com comandos de antes da aula, faltou zerar o histórico no começo.
