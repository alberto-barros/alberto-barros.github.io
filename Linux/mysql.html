Parte 1 · Conceito

O que é MySQL

Entenda o que é um servidor de banco de dados antes de instalar.

MySQL é um SGBD (Sistema Gerenciador de Banco de Dados) relacional: guarda os dados em tabelas e responde a comandos na linguagem SQL (ORACLE, [s.d.]).

Foi criado em 1995 e hoje pertence à Oracle. Funciona no modelo cliente e servidor: o servidor (mysqld) fica rodando e cuidando dos arquivos do banco; o cliente se conecta, faz o login e envia comandos SQL. O servidor devolve o resultado.

Nesta aula o servidor e os clientes ficam na mesma VM Linux Mint: o cliente de terminal mysql e, no fim, o phpMyAdmin no navegador (CANONICAL, [s.d.]).

Anatomia de uma conexão MySQL

Clienteterminal (mysql) ou phpMyAdmin
Servidormysqld, na VM Linux Mint
Porta3306: login e comandos SQL
LinguagemSQL: CREATE, INSERT, SELECT
Acessousuário e senha do MySQL, como ifsc
Parte 1 · Uso

Para que serve o MySQL

Sempre que um sistema precisa guardar informações e encontrá-las rápido.

O MySQL serve para guardar, organizar e consultar dados que um sistema usa o tempo todo.

Alunos e notas de uma escola, produtos e pedidos de uma loja, posts e usuários de um site: tudo isso fica em tabelas. WordPress e Moodle, por exemplo, guardam todo o conteúdo em MySQL. Nesta aula você vai montar o banco escola.

Usos mais comuns do MySQL

Sites e blogsWordPress, Moodle e lojas virtuais em PHP
Sistemas escolaresalunos, cursos, turmas e notas
Comércioprodutos, estoque, clientes e pedidos
Cadastros e loginsusuários e senhas de aplicativos
Parte 1 · Estrutura

Bancos, tabelas e chaves

O vocabulário que você vai usar em todos os passos da aula.

Um servidor guarda vários bancos. Cada banco tem tabelas, e cada tabela tem colunas (campos) e linhas (registros) (CODD, 1970).

A chave primária (PK) é a coluna que identifica cada linha sem repetir, como a matrícula de um aluno. A chave estrangeira (FK) é uma coluna que aponta para a chave primária de outra tabela. É ela que liga um aluno ao seu curso (ELMASRI; NAVATHE, 2018).

Neste roteiro você vai montar o banco escola, com as tabelas cursos e alunos, exatamente como ao lado.

Parte 1 · Por que usar

Vantagens e benefícios do MySQL

Gratuito, rápido e presente em boa parte dos sites da internet (ORACLE, [s.d.]).

Gratuito e aberto

A edição Community tem código aberto (licença GPL) e não custa nada, nem para uso comercial em servidores próprios.

Rápido e estável

Aguenta de um site pequeno a sistemas com milhões de registros, com pouco uso de memória.

Muito usado

Faz parte da pilha LAMP (Linux, Apache, MySQL, PHP). Tem muita documentação, tutoriais e vagas de emprego.

SQL padrão

O que você aprende aqui serve para PostgreSQL, SQL Server e outros bancos relacionais, com poucas diferenças.

Conversa com tudo

PHP, Python, Java, Node.js e quase toda linguagem têm biblioteca pronta para conectar no MySQL.

Interfaces gráficas

Dá para gerenciar pelo terminal ou por programas visuais como phpMyAdmin, DBeaver e MySQL Workbench.

MySQLCriado em 1995 na Suécia. Desde 2010 pertence à Oracle, que comprou a Sun Microsystems, a antiga dona.
MariaDBCriado em 2009 por Michael Widenius, o mesmo criador do MySQL, a partir do código do MySQL, por medo de que a Oracle fechasse o projeto. O nome vem da filha dele, Maria; MySQL vem da filha My.

Passo 02 · Terminal

Proteger a instalação

O script mysql_secure_installation remove o que vem aberto por padrão: usuários anônimos, banco de teste e login do root pela rede. (ORACLE, [s.d.])

  1. 1

    Rode o script de segurança

    terminal
    sudo mysql_secure_installation
  2. 2

    Responda as perguntas

    Digite a letra e aperte Enter. As perguntas aparecem em inglês, nesta ordem:

    PerguntaRespostaPor quê
    VALIDATE PASSWORD component?nNo laboratório, deixa usar senhas simples. Em produção, responda y
    Remove anonymous users?yNinguém entra sem usuário
    Disallow root login remotely?yO root só entra pela própria máquina
    Remove test database?yApaga o banco test, aberto a todos
    Reload privilege tables now?yAplica as mudanças na hora
    Por que o root não tem senhaO script não pede senha para o root e mostra Skipping password set for root. No Linux Mint o root do MySQL entra pelo auth_socket: quem usa sudo no Linux entra como root no MySQL, sem senha. Por isso é mais seguro, e é também por isso que o root não funciona no phpMyAdmin.
  3. 3

    Confira a mensagem final

    saída esperada
    Reloading the privilege tables will ensure that all changes
made so far will take effect immediately.
Success.

All done!

Acessar o MySQL e criar um usuário

Entre como root, crie o banco escola e um usuário que só tem acesso a ele. Dali em diante, trabalhe sempre com esse usuário.

  1. 1

    Entre como root

    O prompt muda para mysql>. Agora você está digitando para o servidor de banco, não para o Linux.

    terminal
    sudo mysql
    Não esqueça o ponto e vírgulaTodo comando SQL termina com ponto e vírgula ;. Se você aperta Enter sem ele, o prompt vira -> e fica esperando. Digite ; e Enter.
  2. 2

    Conheça o servidor

    Os bancos que já aparecem são do próprio MySQL. Não apague nenhum deles.

    mysql
    SHOW DATABASES;

    Crie o banco e o usuário

    Troque a senha se quiser, mas anote. O 'ifsc'@'localhost' quer dizer: usuário ifsc que conecta a partir da própria máquina.

    mysql

CREATE USER 'ifsc'@'localhost' IDENTIFIED BY 'ifsc';

FLUSH PRIVILEGES;

    Saia e entre com o novo usuário

    terminal

    Confira os bancos do usuário

Passo 04 · mysql>

Criar as tabelas

Continue logado como ifsc. Primeiro a tabela cursos, depois alunos, que aponta para ela.

  1. 1

    Escolha o banco

    mysql
    USE escola;
  2. 2

    Crie a tabela cursos

    mysql
    CREATE TABLE cursos (
  id    INT AUTO_INCREMENT PRIMARY KEY,
  nome  VARCHAR(60) NOT NULL,
  turno VARCHAR(10) NOT NULL
);
  3. 3

    Crie a tabela alunos

    A última linha cria a chave estrangeira: o curso_id só aceita um número que exista em cursos.id.

    mysql
    CREATE TABLE alunos (
  id         INT AUTO_INCREMENT PRIMARY KEY,
  nome       VARCHAR(80) NOT NULL,
  email      VARCHAR(100) UNIQUE,
  nascimento DATE,
  curso_id   INT,
  FOREIGN KEY (curso_id) REFERENCES cursos(id)
);
    Tipo ou opçãoO que quer dizer
    INTNúmero inteiro
    VARCHAR(80)Texto de até 80 caracteres
    DATEData no formato AAAA-MM-DD
    AUTO_INCREMENTO MySQL numera sozinho: 1, 2, 3…
    PRIMARY KEYChave primária: não repete e não fica vazia
    NOT NULLCampo obrigatório
    UNIQUEDois alunos não podem ter o mesmo e-mail
    FOREIGN KEY … REFERENCESLiga a coluna à chave primária de outra tabela
  4. 4

    Confira a estrutura

    Na coluna Key, PRI é a chave primária, UNI é único e MUL marca a chave estrangeira.

    mysql
    SHOW TABLES;
DESCRIBE alunos;
    saída esperada

| cursos           |
+------------------+

Passo 07 · Terminal

Fazer backup do banco

O mysqldump gera um arquivo .sql com todos os comandos para recriar o banco do zero. Rode no terminal do Linux, fora do mysql>.

  1. 1

    Gere o backup

    O --no-tablespaces evita um erro de permissão, porque o usuário ifsc não é administrador do servidor.

    terminal
    mysqldump -u ifsc -p --no-tablespaces escola > ~/escola.sql
  2. 2

    Confira o arquivo

    O ls -lh mostra o arquivo e o tamanho. Se ele aparece com alguns KB, o backup foi gerado.

    terminal
    ls -lh ~/escola.sql
    saída esperada
    -rw-rw-r-- 1 ifsc ifsc 3,4K nov 10 10:40 /home/ifsc/escola.sql
  3. 3

    Saiba restaurar

    Se o banco for perdido, o mesmo arquivo devolve tudo. Não precisa rodar agora; guarde o comando.

    terminal
    mysql -u ifsc -p escola < ~/escola.sql
Passo 08 · Terminal

Instalar o phpMyAdmin

O phpMyAdmin é uma interface gráfica para o MySQL que roda como um site, dentro do Apache. Você gerencia o banco clicando, pelo navegador (PHPMYADMIN, [s.d.]).

  1. 1

    Instale o PHP

    O phpMyAdmin é escrito em PHP. Estes pacotes instalam o PHP, o módulo que faz o Apache rodar PHP e a extensão que conecta o PHP ao MySQL.

    terminal
    sudo apt update
sudo apt install php libapache2-mod-php php-mysql
    PacotePara que serve
    phpA linguagem PHP
    libapache2-mod-phpFaz o Apache executar arquivos .php
    php-mysqlDeixa o PHP conversar com o MySQL

    Quando perguntar Deseja continuar? [S/n], digite S e aperte Enter.

  2. 2

    Ative o PHP no Apache

    O a2enmod liga o módulo do PHP no Apache. Depois reinicie o Apache para ele carregar o módulo.

    terminal
    sudo a2enmod php*
sudo systemctl restart apache2

    Se aparecer Module php8.3 already enabled, está certo: a instalação já tinha ativado. Se aparecer que o módulo não existe, veja o nome certo com ls /etc/apache2/mods-available | grep php e use ele, por exemplo sudo a2enmod php8.3.

  3. 3

    Instale o phpMyAdmin

    Sem o -y, porque a instalação faz perguntas.

    terminal
    sudo apt install phpmyadmin
  4. 4

    Escolha o Apache

    Aparece uma tela azul perguntando qual servidor web configurar. Aperte Espaço para marcar apache2 (aparece um *), depois Tab até <Ok> e Enter.

    Configurando phpmyadmin

    Por favor, escolha o servidor web que deverá ser configurado automaticamente para executar o phpMyAdmin.

    Servidor web a ser reconfigurado automaticamente:

    [*] apache2
    [ ] lighttpd
    <Ok>
    Marque o apache2 com EspaçoEsse é o erro mais comum da aula: dar Enter sem marcar o apache2 com Espaço. Se acontecer, veja a solução em 404 Not Found, na seção Mensagens comuns e o que fazer.
  5. 5

    Deixe o dbconfig-common configurar

    O phpMyAdmin precisa de um banco próprio para guardar preferências.

    PerguntaResposta
    Configurar a base de dados para o phpmyadmin com dbconfig-common?<Sim>
    Senha MySQL para phpmyadminDeixe em branco e aperte Enter: ele cria uma senha aleatória
  6. 6

    Recarregue o Apache

    terminal
    sudo systemctl reload apache2
  7. 7

    Confira pelo terminal

    A resposta 200 OK mostra que o Apache já entrega o phpMyAdmin.

    terminal
    curl -sI http://localhost/phpmyadmin/ | head -n 1
    saída esperada
    HTTP/1.1 200 OK

Solução de problemas

Mensagens comuns e o que fazer

Se algo der errado, procure a mensagem aqui.

ERROR 1045 Access denied

Senha errada para o usuário ifsc, ou faltou o -p no comando. Confira e tente de novo.

ERROR 1698 para root

Você rodou mysql -u root sem sudo. O root entra só com sudo mysql.

ERROR 1064 syntax

Erro de digitação no SQL: falta vírgula, aspas ou parêntese. O MySQL mostra o trecho logo depois de near; o erro está ali ou um pouco antes.

ERROR 1046 No database selected

Você saiu e entrou de novo e esqueceu de escolher o banco. Rode USE escola;.

404 Not Found

O apache2 não foi marcado na instalação. Ative a configuração na mão:
sudo ln -s /etc/phpmyadmin/apache.conf /etc/apache2/conf-available/phpmyadmin.conf
sudo a2enconf phpmyadmin
sudo systemctl reload apache2

Erro de senha na instalação

Aparece se você ligou o VALIDATE PASSWORD no Passo 2 e digitou uma senha fraca. Escolha repetir e deixe a senha em branco, ou digite uma com maiúscula, número e símbolo.

Desafio · VM e hospedeira · Acesso remoto

Acessar o MySQL pela máquina hospedeira

Hoje o MySQL só aceita conexões da própria VM. Neste desafio você abre a porta 3306 para a rede interna, cria um usuário que pode entrar a partir da hospedeira e conecta com o DBeaver, um gerenciador gráfico instalado no Windows.

O bind-address é a linha do mysqld.cnf que diz em qual endereço o servidor ouve: 127.0.0.1 é só a VM; 0.0.0.0 são todas as placas de rede (ORACLE, [s.d.]).

No MySQL o usuário é o nome mais o endereço de onde ele conecta. Por isso 'ifsc'@'localhost' e 'ifsc'@'192.168.56.%' são dois usuários diferentes, cada um com as suas permissões.

O % funciona como coringa: vale qualquer número. Assim qualquer máquina da rede 192.168.56.x, como a hospedeira, consegue entrar, mas só no banco escola.

3306Mesma portaO DBeaver conecta na porta padrão do MySQL.
0.0.0.0bind-addressO servidor passa a ouvir em todas as placas de rede.
%Coringa192.168.56.% libera só a rede interna.
ufwFirewallLibere a 3306 só para 192.168.56.0/24.

Passo a passo do desafio

  1. 1

    Guarde a configuração atual VM

    terminal
    sudo cp /etc/mysql/mysql.conf.d/mysqld.cnf /etc/mysql/mysql.conf.d/mysqld.cnf.original
  2. 2

    Mude o bind-address VM

    Abra o arquivo, procure com Ctrl+W a linha bind-address e troque o valor. Salve com Ctrl+O, Enter e saia com Ctrl+X.

    terminal
    sudo nano /etc/mysql/mysql.conf.d/mysqld.cnf
    mysqld.cnf · como deve ficar
    bind-address = 0.0.0.0
  3. 3

    Reinicie e confira a porta VM

    Agora deve aparecer 0.0.0.0:3306. Anote também o IP da VM que começa com 192.168.56.

    terminal
    sudo systemctl restart mysql
sudo ss -tlnp | grep 3306
hostname -I
    saída esperada
    LISTEN 0  151  0.0.0.0:3306  0.0.0.0:*  users:(("mysqld",pid=3381,fd=23))
10.0.2.15 192.168.56.101
  4. 4

    Crie o usuário da rede interna VM

    Entre com sudo mysql e rode. Esse usuário só entra a partir de máquinas da rede 192.168.56.x, e só no banco escola.

    mysql (como root)
    CREATE USER 'ifsc'@'192.168.56.%' IDENTIFIED BY 'ifsc';
GRANT ALL PRIVILEGES ON escola.* TO 'ifsc'@'192.168.56.%';
FLUSH PRIVILEGES;
SELECT user, host FROM mysql.user WHERE user = 'ifsc';
    saída esperada
    +------+--------------+
| user | host         |
+------+--------------+
| ifsc | 192.168.56.% |
| ifsc | localhost    |
+------+--------------+
2 rows in set (0.00 sec)
  5. 5

    Firewall, se estiver ligado VM

    Se sudo ufw status disser Status: active, libere a porta 3306 só para a rede interna.

    terminal
    sudo ufw allow from 192.168.56.0/24 to any port 3306 proto tcp
  6. 6

    Teste a porta pela hospedeira Hospedeira

    No PowerShell do Windows, troque pelo IP da sua VM. Procure TcpTestSucceeded : True.

    PowerShell
    Test-NetConnection 192.168.56.101 -Port 3306
  7. 7

    Conecte com o DBeaver Hospedeira

    Instale o DBeaver Community (gratuito, em dbeaver.io) se ainda não tiver. Clique em Nova conexão (ícone de tomada), escolha MySQL e preencha:

    CampoO que digitar
    Server HostIP da VM, por exemplo 192.168.56.101
    Port3306
    Databaseescola
    Username · Passwordifsc · ifsc

    Clique em Testar conexão. Na primeira vez o DBeaver pede para baixar o driver do MySQL: aceite.

    Public Key Retrieval is not allowedSe aparecer Public Key Retrieval is not allowed, vá na aba Propriedades do driver, procure allowPublicKeyRetrieval e mude para true.
  8. 8

    Prove que está conectado Hospedeira e VM

    • No DBeaver, abra escola › Tabelas › alunos e veja os dados na aba Dados.
    • Abra o Editor SQL (Ctrl+]) e rode a consulta com JOIN do Passo 6.
    • Na VM, com sudo mysql, rode SHOW PROCESSLIST; e procure o usuário ifsc vindo de 192.168.56.1.
Para desfazer o desafioRode sudo cp /etc/mysql/mysql.conf.d/mysqld.cnf.original /etc/mysql/mysql.conf.d/mysqld.cnf, sudo systemctl restart mysql e, no sudo mysql, DROP USER 'ifsc'@'192.168.56.%';
