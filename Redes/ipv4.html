Conceito

O que é endereçamento IPv4?

O endereço IPv4 é o número que identifica um dispositivo em uma rede IP, como o endereço de uma casa identifica onde entregar uma carta.

Ele tem 32 bits, escritos como 4 números decimais de 0 a 255 separados por ponto. Cada número é um octeto (8 bits). Exemplo: 192.168.1.10. Isso dá cerca de 4,3 bilhões de endereços possíveis (2³²).

Todo endereço tem duas partes: a parte de rede, que diz em qual rede o dispositivo está, e a parte de host, que identifica o dispositivo dentro dessa rede. Quem diz onde termina uma e começa a outra é a máscara de sub-rede: os bits 1 da máscara marcam a rede e os bits 0 marcam o host.

Antes de enviar algo, o computador aplica a máscara ao seu IP e ao IP de destino. Se as duas redes forem iguais, ele entrega direto. Se forem diferentes, precisa de um gateway (roteador). Sem gateway, ele simplesmente não envia. Essa é a ideia central da atividade.

Cada linha tem 32 bits (4 bytes) e a largura de cada campo é proporcional aos seus bits. Em verde estão os endereços IP, foco desta aula.

O switch lê apenas o quadro (MAC). Ele não olha o IP e não bloqueia nada entre classes. Quem decide se a comunicação acontece é o próprio PC, comparando as redes na camada 3.

Na prática

Como configurar um IP no Windows ou no Linux

Os exemplos usam 192.168.1.10/24 com gateway 192.168.1.1. Troque pelo endereço da sua rede. Na atividade do Packet Tracer não há roteador, então o gateway fica em branco.

Pela interface gráfica

Win + Rncpa.cplEthernet › PropriedadesIPv4
  • Selecione Protocolo IP Versão 4 (TCP/IPv4) e clique em Propriedades.
  • Marque Usar o seguinte endereço IP.
  • Preencha Endereço IP, Máscara de sub-rede e Gateway padrão. Ao clicar na máscara, o Windows também sugere a máscara padrão da classe.
  • Informe um servidor DNS (ex.: 8.8.8.8) e clique em OK.

No Windows 11 o mesmo ajuste fica em Configurações › Rede e Internet › Ethernet › Atribuição de IP › Editar. Escolha Manuais, ative o IPv4, preencha os campos e clique em Salvar.

cmd · netsh

netsh interface ipv4 set address name="Ethernet" static 192.168.1.10 255.255.255.0 192.168.1.1
netsh interface ipv4 set dnsservers name="Ethernet" static 8.8.8.8 primary
ipconfig /all

Menubuscar “Rede”Cabeada ⚙IPv4Manual

  • Em Cabeada, clique na engrenagem ⚙ para abrir a janela Com fio.
  • Na aba IPv4, mude Endereços de Automático (DHCP) para Manual.

Ferramenta de teste

O que é o ping?

Antes de ver o switch trabalhando, conheça o comando que vamos usar em todos os testes.

O ping é um comando que pergunta a outro dispositivo: “você está aí?” e espera a resposta.

Ele envia uma mensagem ICMP Echo Request (pedido de eco) ao endereço IP de destino. Se o destino recebe, devolve um ICMP Echo Reply (resposta de eco). O nome vem do som do sonar: manda um sinal e escuta o retorno.

O ICMP viaja dentro de um pacote IP, com Protocolo = 1 no cabeçalho que você viu acima. Por isso o ping testa justamente a camada 3, a camada do endereçamento IP.

⇄
Echo Reply10.0.0.11 → PC0

Por que usamos o ping no laboratório

Prova a configuração

Se o ping responde, o IP e a máscara dos dois PCs estão certos e eles estão na mesma rede.

Mostra o limite das redes

Pingar entre classes diferentes falha. É assim que vemos, na prática, que a máscara separa as redes.

Rápido e simples

Não precisa de servidor nem de programa extra. Existe no Windows, no Linux, nos roteadores e no Packet Tracer.

Dá para ver o pacote

No modo Simulation do Packet Tracer cada ping vira um envelope que você acompanha pelo switch.

Ajuda a achar o erro

Falhou na mesma classe? Confira IP, máscara e cabo. O ping aponta onde investigar.

Primeiro pacote perdido

No Packet Tracer o 1º pacote pode dar timed out enquanto o ARP descobre o MAC. Repita o ping antes de concluir.

    Solução de problemas

    Erros comuns

    Ping falha na mesma classe

    Compare IP e máscara dos dois PCs. Um octeto digitado errado ou uma máscara trocada (255.255.0.0 no lugar de 255.0.0.0) já muda a rede calculada.

    Link vermelho

    Cabo errado. Entre PC e switch use Copper Straight-Through. Apague o cabo e ligue de novo na porta FastEthernet0 do PC.

    Link laranja que não fica verde

    O switch ainda está verificando a porta (cerca de 30 s). Aguarde ou use Fast Forward Time.

    “IP address conflict”

    Dois PCs com o mesmo endereço. Cada host precisa de um IP único dentro da rede.

    Máscara que não é a padrão

    Se a máscara foi digitada à mão, confira: A = 255.0.0.0, B = 255.255.0.0, C = 255.255.255.0. Apague e clique de novo no campo para o Packet Tracer sugerir.

    Ping no próprio IP “funciona”

    ping 10.0.0.10 dentro do PC0 sempre responde: o pacote nem sai da placa. Teste sempre contra outro PC.

    No laboratório real o ping não responde

    O Firewall do Windows bloqueia ICMP por padrão. Libere a regra “Compartilhamento de Arquivo e Impressora (Solicitação de Eco - ICMPv4)”.

    Achar que mesma classe é mesma rede

    192.168.1.10 e 192.168.20.10 são classe C, mas redes diferentes. O que decide é o resultado da máscara aplicada ao IP.
