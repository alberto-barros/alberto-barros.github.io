Parte 1 · Conceito

Lendo o prompt do terminal

O prompt é o texto que aparece antes do cursor. Leia o prompt antes de cada comando.

ifsc@linux:~$

O prompt diz quem você é, em qual máquina está, em qual pasta está e se tem poder de administrador.

No Zorin e no Mint o nome da máquina pode ser outro; o formato é o mesmo. O ~ é um atalho para a sua pasta pessoal, /home/ifsc. Quando você entra em outra pasta, o prompt muda: ifsc@linux:~/aula$ mostra que você está em /home/ifsc/aula.

Partes do prompt

ifsco usuário logado
linuxo nome da máquina (hostname)
~a pasta atual; ~ é /home/ifsc
$usuário comum
#root, o superusuário

Usuário comum ou root

$ifsc@linux:~$Usuário comum. Mexe só nas próprias pastas. Use este no dia a dia.
#root@linux:~#Superusuário (root). Pode instalar, configurar e também apagar o sistema. Você ganha esse poder só por um comando, escrevendo sudo na frente (Passo 4).
Parte 1 · Sintaxe

Como um comando é escrito

Primeiro o comando, depois as opções que mudam o jeito dele trabalhar e, por último, o caminho onde ele vai agir. As partes são separadas por espaço (SHOTTS, 2019).

comando -opção caminho
ls -la /home/ifsc

Opção curta tem um traço e uma letra (-a); opção longa tem dois traços e uma palavra (--all). Opções curtas podem ser juntadas: ls -l -a -h é igual a ls -lah.

Partes do comando

comandoo programa que vai rodar: ls lista arquivos
-opçãocomeça com traço e muda o resultado: -l detalhes, -a ocultos
caminhoonde o comando age; sem caminho, usa a pasta atual
Passo 01 · Terminal

Entre no sistema e abra o terminal

Ligue o computador, entre na sua conta e abra o terminal. Os exemplos valem para o Zorin OS e para o Linux Mint.

  1. 1

    Abra o terminal

    1Aperte Ctrl+Alt+T. É o jeito mais rápido nos dois sistemas.
    2Ou abra o menu de aplicativos e procure por Terminal.
    3Confira o prompt, algo como ifsc@linux:~$. O cursor piscando espera o seu comando.
  2. 2

    Confirme quem você é e onde está

    terminal
    whoami                # mostra o usuário: ifsc
hostname              # mostra o nome da máquina
pwd                   # mostra a pasta atual
date                  # data e hora
clear                 # limpa a tela
  3. 3

    Confira a saída

    O whoami deve mostrar o seu usuário (nas aulas, ifsc) e o pwd, a sua pasta pessoal. O nome da máquina pode ser outro.

    saída esperada
    ifsc
linux
/home/ifsc

Parte 1 · Sistema de arquivos

As principais pastas do Linux

No Linux não existe C:\. Tudo começa na raiz, escrita como uma barra /, e cada pasta tem uma função definida pelo padrão FHS (LINUX FOUNDATION, 2015).

árvore de diretórios
/
├── bin     programas básicos
├── boot    kernel e GRUB
├── dev     dispositivos
├── etc     configurações
├── home
│   └── ifsc  ← você (~)
│       ├── Documentos
│       ├── Downloads
│       └── aula
├── media   pendrives
├── root    pasta do root
├── tmp     temporários
├── usr     programas instalados
└── var     logs e cache
PastaPara que serve
/home/ifscSua pasta pessoal, o ~. As pastas da aula ficam aqui
/A raiz. Todas as outras pastas ficam dentro dela
/etcConfigurações
/bin e /usr/binOs programas. O ls e o neofetch ficam em /usr/bin
/rootPasta pessoal do root. Não confunda com a raiz /
/usrProgramas instalados e suas bibliotecas
/varLogs em /var/log
/tmpArquivos temporários, apagados ao reiniciar
/dev e /mediaDispositivos (/dev/sda é o disco) e pendrives

Veja a árvore no seu computador com o comando tree

terminal
sudo apt install tree               # instala o tree (pede a senha; o sudo é explicado no Passo 4)
tree -L 1 /                         # mostra a raiz do sistema em árvore, só o primeiro nível
cd ~                                # vai para a pasta pessoal
tree                                # mostra a estrutura de pastas e arquivos a partir da pasta atual
DicaExecutar tree do diretório home (cd ~) vai mostrar toda a estrutura de arquivos do seu usuário. A opção -L 1 limita a árvore a um nível de profundidade.
Caminho absoluto e relativoO caminho absoluto começa com / e funciona de qualquer lugar: cd /home/ifsc/aula. O caminho relativo parte da pasta atual: se você está em /home/ifsc, basta cd aula. .. é a pasta de cima e . é esta pasta.
Passo 02 · Terminal

Navegue pelas pastas com ls e cd

ls lista o conteúdo da pasta e cd entra em outra pasta. Rode cada linha e observe o prompt mudar.

  1. 1

    Liste o conteúdo das pastas

    terminal
    ls              # lista a pasta atual
ls -l           # lista em detalhes
ls -la          # inclui ocultos (.bashrc)
ls -lh          # tamanhos em K, M, G
ls /etc         # lista outra pasta

    No ls -l, linhas que começam com d são pastas e com - são arquivos. Arquivos que começam com ponto são ocultos.

  2. 2

    Ande entre as pastas

    terminal
    cd /            # vai para a raiz
cd /etc         # caminho absoluto
cd ..           # sobe uma pasta
cd ~            # volta para /home/ifsc
cd -            # volta à pasta anterior
    Cuidado com o espaçoEscreva cd .. com espaço. cd.. grudado não funciona no Linux.
  3. 3

    Confira o caminho

    terminal
    cd /usr/share         # entra em /usr/share
cd ..                 # sobe uma pasta
pwd                   # mostra onde você está
    saída esperada
    /usr
Passo 03 · Terminal

Crie, copie e apague pastas e arquivos

mkdir cria pastas, touch cria arquivos vazios, cp copia, mv move ou renomeia e rm apaga. Faça tudo dentro de ~/aula.

  1. 1

    Escreva e leia um arquivo

    terminal
    cd ~                                                # vai para a pasta pessoal
mkdir aula                                          # cria a pasta aula
cd aula                                             # entra na pasta aula
mkdir redes                                         # cria a pasta redes
touch notas.txt                                     # cria um arquivo vazio
echo "Minha primeira aula de Linux" > notas.txt     # escreve no arquivo
echo "Linha 2" >> notas.txt                         # acrescenta no final
cat notas.txt                                       # mostra o conteúdo
    saída esperada

Linha 2

    Um > apaga e escreve; dois >> acrescentam no final.

    2Digite alguns itens de supermercado, um por linha, como no exemplo abaixo. Pode escolher os seus.
    3Salve com Ctrl+O e Enter. Saia com Ctrl+X.
    4Liste o conteúdo do arquivo com o cat.
    terminal

    Criar e remover pastas e navegar entre elas

Passo 04 · Terminal · sudo

Instale pacotes com apt-get: neofetch e GIMP

O apt-get baixa programas dos repositórios do sistema já com tudo o que eles precisam. Primeiro atualize a lista, depois instale (AOKI, 2024). No Zorin e no Mint, instalar exige poder de administrador: coloque sudo na frente.

  1. 1

    Atualize e instale sudo

    1sudo significa "execute como administrador" e vale só para aquele comando.
    2O terminal pede [sudo] senha para ifsc:. Digite a senha do seu usuário. Nada aparece enquanto você digita.
    3Rode os dois comandos abaixo, na ordem.
    terminal
    sudo apt-get update                     # atualiza a lista de pacotes
sudo apt-get install -y neofetch        # instala o neofetch (-y responde sim)
    Pacote não encontradoSe aparecer Unable to locate package neofetch, a sua versão não tem mais esse pacote. Use o substituto: sudo apt-get install -y fastfetch, e troque neofetch por fastfetch no passo 5.
  2. 2

    Instale e abra o GIMP sudo

    terminal
    sudo apt-get install -y gimp        # instala o GIMP, um editor de imagens
gimp &                              # abre o GIMP e devolve o terminal para você
    Rodar ao fundo com &O & no fim manda o programa rodar ao fundo. Sem ele, o terminal fica preso até você fechar o GIMP. A instalação baixa bastante coisa e pode demorar.
  3. 3

    Teste a vaquinha sudo

    Onde ficam os jogosNo Mint esses jogos ficam em /usr/games. Se der command not found, use o caminho completo: /usr/games/cowsay.
    terminal
    sudo apt-get install -y cowsay fortune-mod sl# instala a vaquinha, as frases e o trem
cowsay "Aprendi Linux no IFSC"              # a vaca fala a frase
cowsay -l                                   # lista os bichos
cowsay -f tux "Agora é o pinguim"           # usa o pinguim no lugar da vaca
fortune | cowsay                            # frase aleatória dita pela vaca
sl                                          # um trem cruza a tela

    Procure, veja e remova pacotes

    terminal
    apt-cache search gimp               # procura pacotes por palavra

    Veja informações do sistema

Passo 05 · Terminal

Faça o neofetch abrir junto com o terminal

Toda vez que o terminal abre, o Bash lê o arquivo oculto ~/.bashrc (FREE SOFTWARE FOUNDATION, 2022). Basta acrescentar o neofetch no final dele. Faça isto sem sudo, com o seu usuário.

  1. 1

    Acrescente o neofetch no .bashrc

    terminal
    whoami                                # precisa mostrar ifsc
cd ~                                  # vai para a pasta pessoal, onde fica o .bashrc
cp ~/.bashrc ~/.bashrc.bkp            # backup antes de mexer
echo "neofetch" >> ~/.bashrc          # acrescenta no final (dois >)
source ~/.bashrc                      # recarrega sem fechar o terminal
    Use dois sinais >>Use dois sinais >>. Com um só > você apaga o .bashrc inteiro. Se isso acontecer, restaure: cp ~/.bashrc.bkp ~/.bashrc.

    Agora feche o terminal e abra outro com Ctrl+Alt+T: o neofetch aparece sozinho. Também dá para editar com nano ~/.bashrc: vá até o fim com Ctrl+End, escreva neofetch, salve com Ctrl+O e saia com Ctrl+X.

Desafio · Compactar, mover e extrair

Faça um backup da sua lista

Compacte o arquivo listas.txt em um único pacote, mova o pacote para outra pasta e extraia o arquivo lá. É assim que se guarda e se transporta arquivos no Linux.

Passo a passo do desafio

  1. 1

    Compacte o arquivo tar

    1Entre em ~/aula e crie o pacote listas.tar.gz com o tar.
    2Confira se o pacote apareceu na pasta.
    ifsc@linux:~/aula$
    cd ~/aula                                   # entra na pasta da aula
tar -czvf listas.tar.gz listas.txt          # compacta listas.txt em listas.tar.gz
ls -lh                                      # lista com tamanhos legíveis
    saída esperada
    listas.txt
-rw-r--r-- 1 ifsc ifsc 148 nov 20 10:12 listas.tar.gz
-rw-r--r-- 1 ifsc ifsc  31 nov 20 10:05 listas.txt
    • c: cria o pacote.
    • z: comprime com gzip.
    • v: mostra o que está fazendo.
    • f: o nome do pacote vem a seguir.
  2. 2

    Mova o pacote para outro diretório

    1Crie a pasta backup e mova o pacote para dentro dela.
    2Liste a pasta backup para conferir.
    ifsc@linux:~/aula$
    mkdir backup                                # cria a pasta de destino
mv listas.tar.gz backup/                    # move o pacote para backup
ls backup                                   # confere o conteúdo de backup
    saída esperada
    listas.tar.gz
  3. 3

    Extraia o pacote Observe

    1Entre em backup e extraia o pacote.
    2Liste a pasta e leia o arquivo extraído com o cat.
    ifsc@linux:~/aula/backup$
    cd backup                                   # entra na pasta backup
tar -xzvf listas.tar.gz                     # extrai o conteúdo do pacote
ls                                          # lista a pasta: o pacote e o arquivo extraído
cat listas.txt                              # mostra a lista de compras
    saída esperada
    listas.txt

Passo 06 · Terminal

Registre o que você fez

Todo comando digitado fica guardado no histórico do Bash. Veja a lista e salve uma cópia em um arquivo para guardar o seu trabalho.

  1. 1

    Veja o histórico do que você fez e salve em um arquivo

    terminal
    history                                     # lista todos os comandos que você digitou
history 10                                  # mostra só os 10 últimos
history >> ~/Downloads/comandos.txt         # salva o histórico no arquivo comandos.txt (dois >)
cat ~/Downloads/comandos.txt                # mostra o arquivo salvo
    O que o >> fazO >> acrescenta no final do arquivo. Se você rodar o comando de novo, o histórico é gravado outra vez, abaixo do anterior. Use > (um só) para começar o arquivo do zero.
Solução de problemas

Mensagens comuns e o que fazer

Se algo der errado, procure a mensagem aqui.

Permission denied / Operation not permitted

O comando precisa de administrador. Repita com sudo na frente, por exemplo sudo apt-get update, e digite a sua senha.

Sorry, try again / 3 incorrect password attempts

A senha do sudo é a do seu usuário, a mesma do login. Ela não aparece enquanto você digita. Confira o Caps Lock.

command not found

Erro de digitação, maiúscula trocada ou programa não instalado. Se for o neofetch, volte ao Passo 4.

Unable to locate package

Nome errado ou lista desatualizada. Rode sudo apt-get update e confira com apt-cache search nome. Sem o pacote neofetch na sua versão, use o fastfetch.

No such file or directory

O caminho não existe a partir de onde você está. Confira com pwd e ls e use o Tab.

Could not get lock /var/lib/dpkg/lock

Outro programa está usando o apt, como o Gerenciador de Atualizações. Feche-o, espere alguns minutos e tente de novo.

O terminal abre sem cores

O .bashrc foi sobrescrito com >. Restaure o backup: cp ~/.bashrc.bkp ~/.bashrc, ou copie o padrão de /etc/skel/.bashrc.

cd..: comando não encontrado

Faltou o espaço. O certo é cd ...
