O objetivo deste repositório é somente para fins didáticos, transformando Pdfs em aulas interativas. 
Cada disciplina tem uma páginas Web destinadas aos ensinamentos de alguns conteúdos específicos.
Cada conteúdo tem uma página web dedicada seja teoria ou laboratório prático para explicação e práticas em sala de aula.
Nenhum dado sensível e de usuário é coletado ou informado, estando totalmente de acordo com a Lei Geral de Proteção de Dados (LGPD).
Dados de usuários utilizados nos materiais são fictícios e servem somente para fins didáticos não representando a realidade.
Os conteúdos não expressam a opnião do Instituto Federal de Santa Catarina, o Docente é total responsável pelos materiais publicados.
As aulas são pensadas e produzidas pelo docente com apoio de Inteligencia Artificial para elaboração de layout e animações.
Os conteúdos são revisados, editados e validados pelo docente para que as instruções sejam verdadeiras.
Os conteúdos são públicos, livre de licença, qualquer interessado pode clonar o repositório, modificar e utilizar sem autorização expressa do autor.
