Conceito

O que é o Apache

Conheça o programa antes de instalar.

O que é

O Apache HTTP Server é um servidor web gratuito e de código aberto, mantido pela Apache Software Foundation desde 1995. É um dos mais usados no mundo.

Para que serve

Ele fica esperando pedidos na porta 80 (HTTP). Quando um navegador pede uma página, o Apache procura o arquivo no computador e envia de volta.

Vantagens

  • Gratuito e de código aberto
  • Fácil de instalar no Linux
  • Estável e muito usado em empresas
  • Muitos módulos: PHP, HTTPS, senhas
  • Muita documentação e tutoriais

Arquivos e pastas criados na instalação

Passo 01

Instalar o servidor web

O Apache é o programa que entrega páginas para o navegador.

  1. 1

    Atualize e instale

    terminal
    sudo apt update
sudo apt install -y apache2 curl

    O curl serve para pedir páginas pelo terminal. Ele será usado nos próximos passos.

Passo 02

Verificar se está ativo

Confira o estado do serviço, ligue e desligue, e peça a página pelo terminal.

  1. 1

    Veja o status

    Procure active (running) em verde. Aperte q para sair.

    terminal
    systemctl status apache2
  2. 2

    Pare, inicie e reinicie

    Rode o systemctl is-active apache2 depois de cada um e compare.

    terminal
    sudo systemctl stop apache2
systemctl is-active apache2     # inactive
sudo systemctl start apache2
systemctl is-active apache2     # active
sudo systemctl restart apache2
systemctl is-active apache2     # active
  3. 3

    Peça a página ao próprio servidor

    HTTP/1.1 200 OK significa que deu certo.

    terminal
    curl -I http://localhost
    saída esperada
    HTTP/1.1 200 OK
Server: Apache/2.4.58 (Ubuntu)
Content-Type: text/html
  4. 4

    Abra no navegador

    Abra o Firefox e digite localhost. Deve aparecer a página do Apache escrito It works!

Passo 03

Analisar os logs de acesso

Cada visita ao site vira uma linha em /var/log/apache2/access.log. Problemas vão para o error.log.

curltailtail -f
  1. 1

    Como ler uma linha do log

    192.168.0.31 - - [16/Oct/2026:19:22:05 -0300] "GET /index.html HTTP/1.1" 200 3138 "-" "Mozilla/5.0 (X11; Linux x86_64) Firefox/131.0"
    IP do visitante: quem acessou
    Data e hora da visita
    Pedido: método e página
    Código de status da resposta
    Navegador usado
    200 OK, página entregue304 não mudou, veio do cache404 página não encontrada403 acesso proibido500 erro no servidor
  2. 2

    Gere algumas visitas

    Uma página que existe e uma que não existe.

    terminal
    curl -s http://localhost
curl -s http://localhost/nao-existe   # gera um 404
  3. 3

    Mostre as últimas linhas

    As 10 últimas linhas do log de acesso.

    terminal
    sudo tail -n 10 /var/log/apache2/access.log
  4. 4

    Acompanhe ao vivo

    Deixe rodando e recarregue a página no Firefox. Saia com Ctrl+C.

    terminal
    sudo tail -f /var/log/apache2/access.log
Passo 04

Colocar a sua página

A página que aparece no navegador é o arquivo /var/www/html/index.html. Vamos trocar por uma sua.

  1. 1

    Guarde a página original

    Entre na pasta do site e renomeie o arquivo.

    terminal
    cd /var/www/html
sudo mv index.html index.html.original
  2. 2

    Crie a nova página

    terminal
    sudo nano index.html
    index.html · modelo
    <html>
<body style="background:#e1f5e5; font-family:sans-serif; text-align:center">
  <h1 style="color:#1d7a2d">Meu servidor web</h1>
  <p>Página criada por Seu Nome - IFSC Garopaba</p>
</body>
</html>
  3. 3

    Salve e saia

    Salve com Ctrl+O e Enter. Saia com Ctrl+X.

  4. 4

    Confira pelo terminal

    Veja o arquivo e peça a página. O seu texto deve aparecer.

    terminal
    cat index.html
curl http://localhost
  5. 5

    Veja no navegador

    Recarregue localhost no Firefox para ver a sua página.

Passo 05

Acessar pelo IP da máquina

Com o IP, outros computadores do laboratório também abrem o seu site.

  1. 1

    Descubra o IP da sua máquina

    terminal
    hostname -I
  2. 2

    Teste o servidor no próprio terminal

    terminal
    curl -I http://localhost
  3. 3

    Abra pelo IP

    No Firefox, digite http:// seguido do seu IP.

Passo 06

Desinstalar o Apache

Faça este passo só no final. Ele remove o servidor e o seu site.

  1. 1

    Pare o serviço

    terminal
    sudo systemctl stop apache2
  2. 2

    Remova o Apache e as configurações

    O autoremove apaga os pacotes que vieram junto.

    terminal
    sudo apt purge -y apache2 apache2-utils apache2-bin apache2-data
sudo apt autoremove -y
    ou
    terminal
    sudo apt-get remove --purge apache2
  3. 3

    Confira que saiu

    O dpkg não deve mostrar nada e o curl deve dar erro de conexão.

    terminal
    dpkg -l | grep apache2
curl -I http://localhost
    saída esperada
    curl: (7) Failed to connect to localhost port 80
  4. 4

    Opcional: apague a pasta do site

    Ela continua no disco.

    terminal
    sudo rm -r /var/www/html

    O purge apaga também as configurações em /etc/apache2. Para remover só o programa e manter as configurações, use sudo apt remove apache2.

Conceito

O que é o Nginx

Outro servidor web muito usado. Leia antes do Passo 7.

O que é

O Nginx (pronuncia-se "engine-x") é um servidor web gratuito e de código aberto, criado por Igor Sysoev em 2004 para aguentar muitos acessos ao mesmo tempo.

Para que serve

Faz o mesmo que o Apache: entrega páginas na porta 80. Também é muito usado como proxy reverso, recebendo os acessos e repassando para outros servidores.

Vantagens

  • Muito rápido para arquivos estáticos (HTML, imagens)
  • Usa pouca memória
  • Aguenta milhares de conexões ao mesmo tempo
  • Ótimo como proxy reverso e balanceador
  • Configuração curta e organizada

Apache x Nginx

CaracterísticaApacheNginx
Lançamento19952004
Como atendeUm processo ou thread para cada conexãoPoucos processos atendem muitas conexões (eventos)
MemóriaUsa mais com muitos acessosUsa menos
Páginas estáticasBomMais rápido
PHPRoda direto com móduloPrecisa de um programa à parte (PHP-FPM)
Arquivo .htaccessAceita, cada pasta pode ter regrasNão aceita, tudo fica na configuração central
Configuração/etc/apache2//etc/nginx/
Logs/var/log/apache2//var/log/nginx/
Comando do serviçosystemctl status apache2systemctl status nginx

Quando usar cada um?

Use o Apache quando

  • O site usa PHP, como WordPress ou Moodle
  • Está em uma hospedagem compartilhada que exige .htaccess
  • Cada pasta precisa ter regras próprias
  • Você está começando e quer mais tutoriais

Use o Nginx quando

  • O site recebe muitos acessos ao mesmo tempo
  • As páginas são estáticas: HTML, CSS e imagens
  • O servidor tem pouca memória
  • Precisa de proxy reverso ou balanceamento, por exemplo na frente de apps em Node.js, Python ou Docker

Usar os dois juntos

É comum em empresas: o Nginx fica na frente, na porta 80, entregando os arquivos estáticos e repassando o resto para o Apache, que roda o PHP em outra porta.

Passo 07

Instalar e configurar o Nginx

Agora vamos colocar outro servidor web no lugar do Apache.

Faça o Passo 6 antes. Se o Apache ainda estiver ligado, ele ocupa a porta 80 e o Nginx não consegue iniciar.

  1. 1

    Instale o Nginx

    terminal
    sudo apt update
sudo apt install -y nginx
  2. 2

    Veja se está ativo

    Procure active (running). Aperte q para sair.

    terminal
    systemctl status nginx
  3. 3

    Peça a página ao servidor

    Agora o cabeçalho mostra Server: nginx.

    terminal
    curl -I http://localhost
    saída esperada
    HTTP/1.1 200 OK
Server: nginx/1.24.0 (Ubuntu)
Content-Type: text/html
  4. 4

    Crie a sua página para o Nginx

    Cole o modelo e troque Seu Nome. Salve com Ctrl+O, Enter e saia com Ctrl+X.

    terminal
    sudo nano /var/www/html/index.html
    index.html · modelo
    <html>
<body style="background:#e1f5e5; font-family:sans-serif; text-align:center">
  <h1 style="color:#1d7a2d">Servidor Nginx</h1>
  <p>Página criada por Seu Nome - IFSC Garopaba</p>
</body>
</html>
  5. 5

    Veja a configuração do site

    A linha root mostra a pasta do site e listen mostra a porta.

    terminal
    grep -E 'listen|root|index' /etc/nginx/sites-available/default
  6. 6

    Teste e recarregue

    Deve aparecer syntax is ok.

    terminal
    sudo nginx -t
sudo systemctl reload nginx
  7. 7

    Confira a página e os logs

    terminal
    curl http://localhost
sudo tail /var/log/nginx/access.log
  8. 8

    Teste pelo IP da máquina

    Troque pelo seu IP e abra também no Firefox.

    terminal
    hostname -I
curl -I http://192.168.0.25
