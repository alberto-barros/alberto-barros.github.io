Parte 1 · Conceito

Lendo o prompt do terminal

O prompt é o texto que aparece antes do cursor. Leia o prompt antes de cada comando.

ifsc@debian:~$

O prompt diz quem você é, em qual máquina está, em qual pasta está e se tem poder de administrador.

O ~ é um atalho para a sua pasta pessoal, /home/ifsc. Quando você entra em outra pasta, o prompt muda: ifsc@debian:~/aula$ mostra que você está em /home/ifsc/aula.

Partes do prompt

ifsco usuário logado
debiano nome da máquina (hostname)
~a pasta atual; ~ é /home/ifsc
$usuário comum
#root, o superusuário

Usuário comum ou root

$ifsc@debian:~$Usuário comum. Mexe só nas próprias pastas. Use este no dia a dia.
#root@debian:~#Superusuário. Pode instalar, configurar e também apagar o sistema. Entre com su - e saia com exit.
Parte 1 · Sintaxe

Como um comando é escrito

Primeiro o comando, depois as opções que mudam o jeito dele trabalhar e, por último, o caminho onde ele vai agir. As partes são separadas por espaço (SHOTTS, 2019).

comando -opção caminho
ls -la /home/ifsc

Opção curta tem um traço e uma letra (-a); opção longa tem dois traços e uma palavra (--all). Opções curtas podem ser juntadas: ls -l -a -h é igual a ls -lah.

Partes do comando

comandoo programa que vai rodar: ls lista arquivos
-opçãocomeça com traço e muda o resultado: -l detalhes, -a ocultos
caminhoonde o comando age; sem caminho, usa a pasta atual

O espaço separa as partes. ls-l grudado é tratado como um comando que não existe. Um nome com espaço precisa de aspas: cd "Área de trabalho".

Parte 1 · Sistema de arquivos

As principais pastas do Linux

No Linux não existe C:\. Tudo começa na raiz, escrita como uma barra /, e cada pasta tem uma função definida pelo padrão FHS (LINUX FOUNDATION, 2015).

árvore de diretórios
/
├── bin     programas básicos
├── boot    kernel e GRUB
├── dev     dispositivos
├── etc     configurações
├── home
│   └── ifsc  ← você (~)
│       ├── Documentos
│       ├── Downloads
│       └── aula
├── media   pendrives
├── root    pasta do root
├── tmp     temporários
├── usr     programas instalados
└── var     logs e cache
PastaPara que serve
/home/ifscSua pasta pessoal, o ~. As pastas da aula ficam aqui
/A raiz. Todas as outras pastas ficam dentro dela
/etcConfigurações, como /etc/hostname e /etc/apt/sources.list
/bin e /usr/binOs programas. O ls e o htop ficam em /usr/bin
/sbinProgramas de administração, como reboot. Só o root usa
/rootPasta pessoal do root. Não confunda com a raiz /
/varLogs em /var/log e pacotes baixados em /var/cache/apt
/tmpArquivos temporários, apagados ao reiniciar
/dev e /mediaDispositivos (/dev/sda é o disco) e pendrives

Caminho absoluto começa com / e funciona de qualquer lugar: cd /home/ifsc/aula. Caminho relativo parte da pasta atual: se você está em /home/ifsc, basta cd aula. .. é a pasta de cima e . é esta pasta.

Passo 04 · VM · root

Vire superusuário (root) com su -

O root é o superusuário: pode instalar programas, mudar configurações e mexer em qualquer pasta. O ifsc troca para o root com su - e volta quando terminar (HERTZOG; MAS, 2020).

  1. 1

    Entre como root root

    1Digite su - e aperte Enter. O nome vem de switch user (trocar de usuário).
    2Em Senha:, digite a senha do root criada na instalação do Debian. Nada aparece enquanto você digita.
    3Confira o prompt: ifsc@debian:~$ virou root@debian:~#. O # avisa que você é o superusuário.
    4Faça a tarefa e saia com exit ou Ctrl+D. O prompt volta a terminar em $.
    terminal
    su -          # pede a senha do root; o prompt muda para #
whoami        # agora mostra: root
pwd           # a pasta do root: /root
exit          # volta a ser ifsc
whoami        # mostra: ifsc de novo
  2. 2

    Por que o traço

    ComandoO que acontece
    su -Entra como root com o ambiente completo: vai para /root e enxerga os programas de /sbin. Use sempre este.
    suVira root, mas continua com o ambiente do ifsc. Comandos como reboot dão "comando não encontrado".
    exitSai do root e volta para o usuário anterior.

    Como root nada pede confirmação, e um rm errado pode apagar o sistema. Fique no root só o tempo da tarefa e volte com exit.

Passo 05 · VM · root

Instale pacotes com apt-get

O apt-get baixa programas dos repositórios do Debian já com tudo o que eles precisam. Primeiro atualize a lista, depois instale (AOKI, 2024).

  1. 1

    Atualize e instale root

    root@debian:~#
    apt-get update                       # atualiza a lista de pacotes
apt-get install -y htop fastfetch    # instala os dois (-y responde sim)
apt-get install -y tree mc           # mais dois úteis
  2. 2

    Procure, veja e remova pacotes root

    root@debian:~#
    apt-cache search monitor             # procura pacotes por palavra
apt-cache show htop                  # detalhes de um pacote
apt-get remove mc                    # remove um programa
apt-get upgrade                      # atualiza tudo que está instalado
apt-get autoremove                   # limpa dependências sem uso

    apt e apt-get fazem quase o mesmo. O apt tem barra de progresso; o apt-get é o mais usado em scripts e tutoriais. Nesta aula usamos o apt-get.

  3. 3

    Confira a instalação

    terminal
    which htop fastfetch
    saída esperada
    /usr/bin/htop
/usr/bin/fastfetch

Passo 08 · VM

Faça o fastfetch abrir junto com o terminal

Toda vez que o terminal abre, o Bash lê o arquivo oculto ~/.bashrc (FREE SOFTWARE FOUNDATION, 2022). Basta acrescentar o fastfetch no final dele. Faça isto como ifsc, não como root.

  1. 1

    Acrescente o fastfetch no .bashrc

    terminal
    whoami                        # precisa mostrar ifsc
cp ~/.bashrc ~/.bashrc.bkp    # backup antes de mexer
echo "fastfetch" >> ~/.bashrc   # acrescenta no final (dois >)
source ~/.bashrc              # recarrega sem fechar o terminal

    Use dois sinais >>. Com um só > você apaga o .bashrc inteiro. Se isso acontecer, restaure: cp ~/.bashrc.bkp ~/.bashrc.

  2. 2

    Confira a última linha

    terminal
    tail -n 1 ~/.bashrc
    saída esperada
    fastfetch

    Também dá para editar com nano ~/.bashrc: vá até o fim com Ctrl+End, escreva fastfetch, salve com Ctrl+O e saia com Ctrl+X.

Solução de problemas

Mensagens comuns e o que fazer

Se algo der errado, procure a mensagem aqui.

Permission denied / Are you root?

O comando precisa de administrador. Rode su -, digite a senha do root e repita. O prompt deve terminar em #.

su: Falha de autenticação

A senha do root está errada. É a senha do root criada na instalação, não a do ifsc. Confira o Caps Lock.

command not found

Erro de digitação, maiúscula trocada ou programa não instalado. Para reboot, faltou o traço em su -.

Unable to locate package

Nome errado ou lista desatualizada. Rode apt-get update e confira com apt-cache search nome.

No such file or directory

O caminho não existe a partir de onde você está. Confira com pwd e ls e use o Tab.

Could not get lock /var/lib/dpkg/lock

Outro apt já está rodando. Espere alguns minutos e tente de novo. Se continuar, apague a trava como root: rm /var/lib/dpkg/lock-frontend /var/lib/dpkg/lock

O terminal abre sem cores

O .bashrc foi sobrescrito com >. Restaure o backup: cp ~/.bashrc.bkp ~/.bashrc, ou copie o padrão de /etc/skel/.bashrc.

cd..: comando não encontrado

Faltou o espaço. O certo é cd ...
