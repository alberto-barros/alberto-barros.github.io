🏛️ Projeto Aulas Dinâmicas
Uma plataforma digital elegante que conecta conhecimentos na área da Informática, desenvolvida especialmente para aulas no Instituto Federal de Santa Catarina

📖 Sobre o Projeto
O objetivo deste repositório é somente para fins didáticos, transformando Pdfs em aulas interativas. Cada disciplina tem uma página web para ensinamentos de conteúdos específicos.
Aulas teóricas e práticas ganham vida com aulas mais explicativos, animações, exercícios, desafios e Quiz.

💡 Autoria
Desenvolvido por Alberto Felipe com apoio de Inteligencia Artificial para elaboração de layout e animações.As aulas são pensadas e produzidas pelo docente com apoio de Inteligencia Artificial para elaboração de layout e animações.Os conteúdos são revisados, editados e validados pelo docente para que as instruções sejam verdadeiras.
