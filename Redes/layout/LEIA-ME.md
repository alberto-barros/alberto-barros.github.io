# Kit de layout · Redes (IFSC Câmpus Garopaba)

- `modelo.html` — página-modelo completa e autocontida (topo, hero, seção, checklist, desafio, erros, quiz, referências, rodapé). Copie e troque só o conteúdo.
- `ifsc-redes.css` — todo o CSS (tokens claro/escuro, ícones 3D, tabelas, terminais, passos, quiz...).
- `ifsc-redes-icons.svg.html` — sprite de ícones (`#i-...`) e a marca do IFSC.
- `ifsc-redes.js` — comportamento: topo, menu Tópicos, copiar código, checklist e quiz (`window.IFSC_QUIZ`).

Referência visual completa: `../ipv4.html`.
