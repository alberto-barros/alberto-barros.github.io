Primeiros passos no terminal do Debian

O Debian já está instalado. Agora você vai navegar pelas pastas, criar arquivos, virar administrador com su -, instalar programas com o apt-get, abrir o htop e o fastfetch e, no fim, instalar a interface gráfica KDE Plasma.

01Conceito

Lendo o prompt do terminal

O prompt é o texto que aparece antes do cursor. Ele diz quem você é, em qual máquina está, em qual pasta está e se tem poder de administrador. Leia o prompt antes de cada comando.

ifsc@debian:~$
ifsc · o usuário logado
debian · o nome da máquina (hostname)
~ · a pasta atual. O ~ é a sua pasta pessoal: /home/ifsc
$ · usuário comum. Quando aparece #, você é o root
ifsc@debian:~/aula$

Usuário comum

Pode mexer só nas próprias pastas. Use este usuário no dia a dia. Aqui o prompt mostra que você está em /home/ifsc/aula.

root@debian:~#

Root (administrador)

Pode tudo: instalar programas, mudar configurações e também apagar o sistema. Entre com su -, faça a tarefa e saia com exit.

No Linux, maiúsculas e minúsculas são diferentes. Aula, aula e AULA são três pastas diferentes. Comandos também: LS não existe, o certo é ls.

02Sintaxe

Como um comando é escrito

Quase todo comando segue a mesma ordem: primeiro o comando, depois as opções que mudam o jeito dele trabalhar e, por último, o caminho ou alvo onde ele vai agir. As partes são separadas por espaço.

comando -opção caminho
ls -la /home/ifsc
comando · o programa que vai rodar: ls lista arquivos
-opção · começa com traço e muda o resultado: -l mostra detalhes e -a mostra os ocultos
caminho · onde o comando age: a pasta /home/ifsc. Sem caminho, ele usa a pasta atual

Opções curtas e longas

Opção curta tem um traço e uma letra: -a. Opção longa tem dois traços e uma palavra: --all. As duas fazem o mesmo: ls -a = ls --all.

Juntar opções

Opções curtas podem ser escritas juntas: ls -l -a -h é igual a ls -lah. A ordem das letras não importa.

Partes opcionais

Opção e caminho nem sempre são obrigatórios: ls sozinho funciona. Alguns comandos pedem mais de um caminho: cp origem destino.

Rode os exemplos na ordem, de cima para baixo: cada um usa o que o anterior criou. No fim, a pasta de treino é apagada.

#ExemploComandoOpçãoCaminhoO que acontece
1cd ~cd(nenhuma)~Vai para a pasta pessoal /home/ifsc
2mkdir -p treino/lab1mkdir-ptreino/lab1Cria as pastas treino e lab1 de uma vez
3touch treino/notas.txttouch(nenhuma)treino/notas.txtCria um arquivo vazio dentro de treino
4cp treino/notas.txt treino/lab1/cp(nenhuma)treino/notas.txt treino/lab1/Copia o arquivo para a pasta lab1
5ls -l treinols-ltreinoLista treino em detalhes: lab1 e notas.txt
6rm -r treinorm-rtreinoApaga a pasta treino e tudo dentro dela
7free -hfree-h(nenhum)Memória em G e M

Descubra as opções de qualquer comando: comando --help

Ninguém decora todas as opções. Escreva o comando seguido de --help e ele mostra a forma de uso e a lista de opções, cada uma com uma explicação curta.

  • A linha Uso: mostra a sintaxe. O que está entre colchetes [OPÇÃO] é opcional e ... indica que pode repetir.
  • Cada opção aparece na forma curta e longa: -a, --all.
  • Se o texto for maior que a tela, use ls --help | less: role com as setas e saia com q.
  • Para o manual completo, use man ls (também sai com q).
ifsc@debian:~$
ls --help            # opções do ls
mkdir --help         # opções do mkdir
cp --help            # opções do cp
free --help          # opções do free
apt-get --help       # opções do apt-get
ls --help | less     # lê com rolagem (q sai)
man ls               # manual completo
trecho da saída de ls --help
Uso: ls [OPÇÃO]... [ARQUIVO]...
Lista informações sobre os ARQUIVOs (o diretório
atual por padrão).

  -a, --all          não ignora entradas iniciadas por .
  -h, --human-readable  tamanhos como 1K 234M 2G
  -l                 usa formato de lista longa
  -R, --recursive    lista subdiretórios recursivamente

O espaço separa as partes. ls-l grudado é tratado como um comando que não existe. E um nome com espaço precisa de aspas: cd "Área de trabalho", senão o terminal entende três caminhos.

03Sistema de arquivos

As principais pastas do Linux

No Linux não existe C:\. Tudo começa na raiz, escrita como uma barra /. Pendrives, HDs e até dispositivos aparecem como pastas dentro dela.

/
├── bin     programas básicos
├── boot    kernel e GRUB
├── dev     dispositivos
├── etc     configurações
├── home
│   └── ifsc  ← você (~)
│       ├── Documentos
│       ├── Downloads
│       └── aula
├── media   pendrives
├── root    pasta do root
├── tmp     temporários
├── usr     programas instalados
└── var     logs e cache
/home/ifscSua pasta pessoal, o ~. Documentos, downloads e as pastas da aula ficam aqui.
/A raiz. Todas as outras pastas ficam dentro dela.
/etcArquivos de configuração do sistema, como /etc/hostname e /etc/apt/sources.list.
/bin e /usr/binOs programas. O ls está em /usr/bin/ls; o htop também vai parar lá.
/sbinProgramas de administração, como usermod e reboot. Só o root usa.
/rootA pasta pessoal do root. Não confunda com a raiz /.
/varDados que mudam: logs em /var/log e pacotes baixados em /var/cache/apt.
/tmpArquivos temporários. São apagados quando o sistema reinicia.
/dev e /mediaDispositivos (/dev/sda é o disco) e pendrives montados.

Caminho absoluto começa com / e funciona de qualquer lugar: cd /home/ifsc/aula. Caminho relativo parte da pasta atual: se você já está em /home/ifsc, basta cd aula. Dois pontos .. significam "a pasta de cima" e um ponto . significa "esta pasta".

05Produtividade

Atalhos que economizam digitação

Quem usa terminal quase não digita o comando inteiro. Aprenda estes atalhos hoje e use em todos os exercícios.

Tab

Autocompletar

Digite o começo e aperte Tab: cd Doc vira cd Documentos/. Se houver várias opções, aperte Tab duas vezes para ver a lista.

↑↓

Comandos anteriores

A seta para cima traz de volta o último comando. Edite e aperte Enter.

history

Histórico

Lista tudo o que você digitou, numerado. !25 repete o comando 25 e !! repete o último.

Ctrl+R

Buscar no histórico

Digite parte de um comando antigo, como apt, e ele aparece. Enter executa.

Ctrl+C

Cancelar

Interrompe o programa que está rodando, como um ping sem fim. No terminal não é copiar.

Ctrl+L

Limpar a tela

Igual ao comando clear. O histórico continua guardado.

Ctrl+Shift+C / V

Copiar e colar

No terminal gráfico (Konsole, GNOME Terminal), copiar e colar levam o Shift.

q · F10

Sair de programas

q fecha o top, o htop e o man. No htop também vale F10.

06Atividade

Passo a passo no Debian

Siga a ordem. Cada bloco preto tem um botão Copiar, mas o objetivo é digitar: é assim que se aprende. Os blocos com borda vermelha no título rodam como root.

  1. 1

    Entre no sistema e abra o terminal

    Ligue a VM e faça login com usuário ifsc e senha ifsc. A senha não aparece enquanto você digita, é normal. Se o Debian foi instalado sem interface gráfica, você já cai direto no terminal (tela preta). Confirme quem você é e onde está:

    ifsc@debian:~$
    whoami       # mostra o usuário: ifsc
hostname     # mostra o nome da máquina
pwd          # mostra a pasta atual: /home/ifsc
date         # data e hora
clear        # limpa a tela
  2. 2

    Navegue pelas pastas com ls e cd

    ls lista o conteúdo da pasta. cd entra em outra pasta. Rode cada linha e observe como o prompt muda.

    listar
    ls            # lista a pasta atual
ls -l         # lista em detalhes
ls -la        # inclui ocultos (.bashrc)
ls -lh        # tamanhos em K, M, G
ls /etc       # lista outra pasta
    navegar
    cd /          # vai para a raiz
cd /etc       # caminho absoluto
cd ..         # sobe uma pasta
cd ~          # volta para /home/ifsc
cd -          # volta à pasta anterior
    • No ls -l, linhas que começam com d são pastas e com - são arquivos.
    • Escreva cd .. com espaço. cd.. grudado não funciona no Debian.
    • Arquivos que começam com ponto, como .bashrc, são ocultos. Só aparecem com ls -a.
  3. 3

    Crie pastas e arquivos

    Volte para a sua pasta pessoal e monte a estrutura da aula. mkdir cria pastas e touch cria arquivos vazios.

    ifsc@debian:~$
    cd ~
mkdir aula                       # cria a pasta aula
cd aula
mkdir redes linux                # cria duas pastas de uma vez
mkdir -p linux/lab1/scripts      # cria a árvore inteira com -p
touch notas.txt                  # cria um arquivo vazio
touch linux/lab1/a.txt linux/lab1/b.txt
echo "Minha primeira aula de Linux" > notas.txt   # escreve no arquivo
echo "Linha 2" >> notas.txt      # acrescenta no final
cat notas.txt                    # mostra o conteúdo
ls -R                            # lista tudo, com as subpastas

    Agora, ainda dentro de ~/aula e usando o que você acabou de criar, copie, renomeie e apague:

    ifsc@debian:~/aula$
    cp notas.txt copia.txt           # copia
mv copia.txt backup.txt          # renomeia
mv backup.txt redes/             # move para a pasta redes
nano notas.txt                   # edita (Ctrl+O salva, Ctrl+X sai)
rm redes/backup.txt              # apaga o arquivo
rmdir redes                      # apaga pasta vazia
rm -r linux/lab1                 # apaga lab1 com a.txt, b.txt e scripts
ls -R                            # confere o que sobrou

    O rm não manda para a lixeira. O arquivo some de vez. Confira o caminho com ls antes de apagar e nunca rode rm -r na raiz /.

  4. 4

    Vire superusuário (root) com su - root

    O root é o superusuário do Linux: a conta que administra o sistema e pode instalar programas, mudar configurações e mexer em qualquer pasta. O usuário ifsc não tem esse poder. Para instalar pacotes, você troca temporariamente para o root com o comando su - e volta para o ifsc quando terminar.

    1Digite su - e aperte Enter. O nome vem de switch user (trocar de usuário); sem dizer qual, ele troca para o root.
    2Em Senha:, digite a senha do root criada na instalação do Debian (não é a senha do ifsc, a menos que vocês tenham usado a mesma). Nada aparece enquanto você digita.
    3Confira o prompt: ifsc@debian:~$ virou root@debian:~#. O # avisa que você é o superusuário.
    4Faça a tarefa de administrador (instalar, configurar) e saia com exit ou Ctrl+D. O prompt volta a terminar em $.
    ifsc@debian:~$ → root@debian:~#
    su -          # pede a senha do root; o prompt muda para #
whoami        # agora mostra: root
pwd           # a pasta do root: /root
exit          # volta a ser ifsc
whoami        # mostra: ifsc de novo
    ComandoO que acontece
    su -Entra como root com o ambiente completo dele: vai para /root e enxerga os programas de administração em /sbin. Use sempre este.
    suVira root, mas continua com o ambiente do ifsc. Comandos como reboot e usermod dão "comando não encontrado".
    exitSai do root e volta para o usuário anterior.

    Como root nada pede confirmação, e um rm errado pode apagar o sistema. Fique no root só o tempo da tarefa, confira sempre se o prompt termina em # antes de instalar e volte com exit.

  5. 5

    Instale pacotes com apt-get root

    O apt-get baixa programas dos repositórios do Debian já com tudo o que eles precisam. Primeiro atualize a lista de pacotes, depois instale.

    root@debian:~#
    apt-get update                       # atualiza a lista de pacotes
apt-get install -y htop fastfetch    # instala os dois (-y responde sim)
apt-get install -y tree mc           # mais dois úteis
apt-cache search monitor             # procura pacotes por palavra
apt-cache show htop                  # detalhes de um pacote
apt-get remove mc                    # remove um programa
apt-get upgrade                      # atualiza tudo que está instalado
apt-get autoremove                   # limpa dependências sem uso

    O fastfetch mostra o logo do Debian e um resumo do sistema.

    apt e apt-get fazem quase o mesmo. O apt tem barra de progresso e é feito para pessoas; o apt-get é o mais usado em scripts e tutoriais. Nesta aula usamos o apt-get.

  6. 6

    Chame os programas e veja a memória e os processos

    Saia do root com exit. Para abrir um programa, digite o nome dele.

    ifsc@debian:~$
    exit           # se ainda estiver como root
fastfetch      # resumo do sistema com o logo do Debian
free -h        # memória RAM e swap em G/M
df -h          # espaço em disco
uname -r       # versão do kernel
top            # processos em tempo real (q para sair)
htop           # o top colorido e interativo (F10 ou q)
tree ~/aula    # desenha a árvore de pastas
which htop     # mostra onde o programa está: /usr/bin/htop
    No htopO que faz
    F3 ou /Procura um processo pelo nome
    F5Mostra os processos em árvore (quem abriu quem)
    F6Escolhe a coluna de ordenação (CPU, memória)
    F9Encerra o processo selecionado
    F10 ou qSai do htop
  7. 7

    Use o Tab, o histórico e o manual

    Treine o Tab de verdade: digite só o começo e deixe o terminal completar.

    ifsc@debian:~$
    cd au          # aperte Tab: vira cd aula/
fast           # aperte Tab: vira fastfetch
ht             # Tab Tab: lista htop, htpasswd...
history        # tudo que você digitou, numerado
history 10     # só os 10 últimos
!!             # repete o último comando
man ls         # manual do ls (q para sair)
ls --help      # ajuda rápida
  8. 8

    Faça o fastfetch abrir junto com o terminal

    Toda vez que o terminal abre, o Bash lê o arquivo oculto ~/.bashrc. Basta acrescentar o fastfetch no final dele. Faça isto como ifsc, não como root: senão só o root vê o fastfetch.

    ifsc@debian:~$
    whoami                        # precisa mostrar ifsc
cp ~/.bashrc ~/.bashrc.bkp    # backup antes de mexer
echo "fastfetch" >> ~/.bashrc   # acrescenta no final (dois >)
tail -n 3 ~/.bashrc           # confere a última linha
source ~/.bashrc              # recarrega sem fechar o terminal
    • Use dois sinais >>. Com um só > você apaga o .bashrc inteiro e deixa só a palavra fastfetch. Se isso acontecer, restaure: cp ~/.bashrc.bkp ~/.bashrc.
    • Também dá para editar com nano ~/.bashrc, ir até o fim com Ctrl+End, escrever fastfetch, salvar com Ctrl+O e sair com Ctrl+X.
    • Para desfazer, apague a linha com nano ~/.bashrc.
  9. 9

    Instale a interface gráfica KDE Plasma com o tasksel root

    O tasksel instala "tarefas": grupos prontos de pacotes, como um ambiente de área de trabalho completo. Primeiro instale o próprio tasksel com o apt-get. O KDE baixa mais de 1 GB, então deixe a VM ligada e na tomada.

    root@debian:~#
    su -                          # se ainda não estiver como root
apt-get update
apt-get install -y tasksel    # instala o tasksel
tasksel                       # abre o menu de tarefas

    No menu azul, mova com as setas e marque com a Barra de espaço:

    Seleção de software
    [*] Ambiente de área de trabalho Debian
    [ ] ... GNOME
    [ ] ... Xfce
    [*] ... KDE Plasma
    [ ] ... Cinnamon
    [ ] servidor web
    [ ] servidor SSH
    [*] utilitários de sistema padrão
    <Ok><Cancelar>
    • Marque Ambiente de área de trabalho Debian e KDE Plasma. Desmarque o GNOME e o servidor SSH se vierem marcados.
    • Aperte Tab para chegar no <Ok> e depois Enter. Aguarde até voltar ao prompt #.

08Solução de problemas

Mensagens comuns e o que fazer

Permission denied / Are you root?

O comando precisa de administrador. Rode su -, digite a senha do root e repita. O prompt deve terminar em #.

su: Falha de autenticação

A senha do root está errada. Lembre que é a senha do root criada na instalação, não a do ifsc. Confira se o Caps Lock está desligado.

command not found

Erro de digitação, maiúscula trocada ou programa não instalado. Para usermod e reboot, faltou o traço em su -.

Unable to locate package

Nome errado ou lista desatualizada. Rode apt-get update e confira com apt-cache search nome. Lembre que o nome é fastfetch, sem hífen.

No such file or directory

O caminho não existe a partir de onde você está. Confira com pwd e ls, e use o Tab para não errar o nome.

Could not get lock /var/lib/dpkg/lock

Outro apt já está rodando, talvez em outro terminal ou atualizando sozinho. Espere alguns minutos e tente de novo. Se continuar, apague a trava como root: rm /var/lib/dpkg/lock-frontend /var/lib/dpkg/lock

O terminal abre vazio, sem cores

Provavelmente o .bashrc foi sobrescrito com >. Restaure o backup: cp ~/.bashrc.bkp ~/.bashrc, ou copie o padrão de /etc/skel/.bashrc.
